  - Defects found and fixed:
    1. Date windows were anchored to "now", so every discontinued series charted empty at
       anything except All Time. Windows are now anchored to each series' last observation.
    2. Every date-range change refetched the series. Full history is now fetched once and
       windowed locally; FRED returns up to 100,000 observations per request.
    3. `getMultipleSeriesObservations` used a throwing task group, so one failing
       comparison series aborted the batch and blanked the chart. Loading is now
       per-series, reporting failures individually.
    4. A cancelled search returned before clearing `isLoading`, leaving the sidebar
       spinning forever. Search state is now guarded by a generation token.
    5. Opening a favorite that failed to load logged the error and did nothing visible.
       The detail pane now shows a retryable error.
    6. `SeriesStatistics` substituted sentinels for undefined metrics
       (`firstValue == 0 ? min : firstValue`). Undefined metrics are now optional and
       render as "n/a".
    7. Standard deviation printed unscaled next to scaled means ("$29.0T" beside
       "1,234.56"). All dispersion figures now use the same scale.
    8. Differences between percentages were labelled "%" instead of percentage points.
    9. Positive levels were prefixed with "+", and compact magnitudes dropped their
       decimal ("+$29T" instead of "$29.0T").
    10. Column headers named the raw units while the values were scaled — a
        "Billions of Dollars" column showing dollars, overstating by 10^9. Chart and table
        now carry separate, accurate labels.
    11. `UnitDescriptor` and `NumberFormatter` were rebuilt per value per render; the data
        table was rebuilt on every state change. Parsing is memoised and rows are lazy.
    12. Year-over-year matching tolerance was wide enough for an annual series to match its
        own observation and report 0% growth. (Caught by a new test, then fixed.)
    13. The Xcode project carried a dangling build file that rendered as
        "(null) in Resources", plus a dozen duplicate loose file references.
    14. Two UI tests were unconditionally skipped, so a green run proved nothing.
  - Features added:
